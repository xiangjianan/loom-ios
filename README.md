# Loom for iOS

原生 SwiftUI 多模型并行对话工作台，支持 **iPhone 和 iPad**。使用系统原生 Liquid Glass，最低需要 **iOS / iPadOS 26**。

## 两种阅读方式

- **iPhone**：单列回答，顶部玻璃模型标签；点击标签或左右滑动切换，顶部只保留标签与更多菜单。底部输入框随键盘抬升，支持换行，发送按钮位于输入框内部右下角。
- **iPad**：宽窗口并排阅读模型回答，各列独立滚动；列数多时支持横向滚动。窗口宽度小于 700 pt 时自动使用单列标签布局。
- **文本高亮**：长按选择文字后，点击系统菜单中的“高亮”，加入下一轮引用。默认单击一句快捷高亮；相邻高亮自动合成一个引用，再次点击其中任一句取消整块；设置中可改为双击。按句号、问号和感叹号等句末标点划分，也按逗号、冒号和分号分割，顿号不分割。拖动选区手柄到阅读区域边缘可自动滚动。删除引用标签会同步取消对应原文高亮，恢复 Markdown 样式。扩大选区会替换重叠引用，避免重复。
- **SVG 图像**：回答中的完整 SVG 标签及 SVG/XML/HTML 代码块会直接显示矢量图像，自适应阅读列宽。SVG 周围文字继续保留原生选区和高亮。
- **引用追问**：所有模型收到相同的问题和带来源、型号、轮次的高亮引用；各自保留独立对话上下文。
- **1–5 个模型**：支持 OpenAI 兼容接口与 Anthropic，内置 OpenAI、Claude、Gemini、DeepSeek、千问、Kimi、GLM、Grok 厂商预设；自动填写接口，输入 Key 后自动获取在线型号，支持手动型号输入。
- **历史对话**：本地保存对话、草稿、引用和高亮，支持搜索、轮次跳转和分享回答。阅读时右侧浮现轮次横杠，支持点击跳转和按住拖动切换。使用系统红色左滑删除操作，完整左滑可直接触发系统“取消 / 删除”确认弹框。
- **备份**：左上角双横线 → 侧栏底部「备份」，通过系统文件窗口保存至本机或 iCloud 云盘，也可从任一位置导入。包含对话、高亮、引用、草稿、模型配置及偏好；API Key 默认不导出，可单独勾选。导入前检查格式，并保留原有本地记录。
- **请求控制**：并行请求、停止生成、单列失败重试；切换对话会先取消当前请求。


模型设置中点击「排序」可拖动调整模型顺序，自动保存并同步到对话页面。已发送消息旁点击「复制」可复制提问正文。

## 在 Xcode 中运行

1. 用 **Xcode 26 或更高版本** 打开 `Loom.xcodeproj`。
2. 选择 `Loom` scheme 和 iPhone / iPad 模拟器，运行。
3. 点左上角双横线 → 侧栏底部「模型设置」，选择预设厂商，接口自动填写；输入 API Key 后自动获取在线型号，选择后保存。
4. 同时向所有配置模型发送问题；只需要一个模型时，可以在设置中移除另一个。

真机运行时，在 `Signing & Capabilities` 中选择自己的开发团队。仓库不包含签名证书、描述文件或开发团队 ID。

项目配置由 `project.yml` 管理；修改目标或构建设置后可重新生成：

```sh
brew install xcodegen
xcodegen generate
```

项目没有第三方运行时依赖。默认界面为中文，支持系统深色模式、动态字体和 VoiceOver。原生玻璃效果由 `glassEffect`、`GlassEffectContainer`、玻璃按钮样式和系统工具栏提供。

## 后端与数据

默认**直接连接模型服务商**，不依赖 Loom 后端。在设置中开启「使用转发服务」后，可复用网页后端。预填转发服务：`https://relay.minidesk.online:8443/loom`，兼容网页 Loom 的 `/api/chat` 与 `/api/models`。可在设置中更换 HTTPS 转发服务。

- API Key 保存在系统钥匙串（`WhenUnlockedThisDeviceOnly`），不写入日常对话 JSON，不提交到仓库。只有勾选「同时备份 API Key」时，导出的备份 JSON 才会包含密钥；该文件请保存到可信位置。
- 直连模式仅向配置的服务商发送 API Key、对话上下文和高亮引用；转发模式还会经过所配置的转发服务。请使用可信任的转发服务，并查看对应提供商的数据政策。
- 对话存于 App 沙盒的 `Application Support/Loom/state.json`，使用原子写入和系统文件保护。
- 本地记录损坏时保留原文件并显示提示，不覆盖原记录。
- 支持手动导入 / 导出备份以迁移 iOS 设备；本版本不提供账号、自动跨设备同步或网页历史迁移。
- 本版本使用完整响应接口，回答完成后显示；暂不支持流式输出。
- 后台运行并无完成保证。应用被结束后，再次打开会将未完成请求标为可重试。

删除 App 会删除本地对话；钥匙串凭据可能被系统保留。正式发布前需要准备隐私政策、App Store 隐私披露、签名和真实服务商联调。

### 1.7.0：备份分类与轮次标记

“更多”菜单统一使用“备份”。备份页面分为“导出到文件”（系统文件导入/导出）和“iCloud 原生备份”（CloudKit 私有数据库，直接备份/恢复）。云端使用一个可更新的最新归档，恢复前仍需确认；API Key 默认不包含。轮次横杠移近系统滚动条，删除装饰竖线，保留原生滚动条拖动和横杠点击/拖动。

原生 iCloud 需要开发者账户开通容器 `iCloud.online.minidesk.loom`、CloudKit 服务和匹配描述文件。当前已安装版本的签名不包含该权限，因此界面明确提示暂不可用，不会把文件导出当成直接云备份。`Configuration/iCloud.entitlements` 提供权限配置；获得匹配签名后，构建时同时设置 `CODE_SIGN_ENTITLEMENTS=Configuration/iCloud.entitlements` 和 `SWIFT_ACTIVE_COMPILATION_CONDITIONS='DEBUG LOOM_ICLOUD'`（Release 使用 `LOOM_ICLOUD`），并在 CloudKit Console 将 `LoomBackup` 类型的 `archive`（Asset）和 `createdAt`（Date/Time）部署至生产环境后再发布正式版。首次开发环境保存可创建 schema；生产环境不能自动创建。

已验证普通版本及启用 `LOOM_ICLOUD` 的模拟器版本编译。真实云端往返验证需在获得 iCloud 签名、登录测试 iCloud 账户后进行。

本轮验证：30 项单元测试、3 项 iPhone 界面测试、4 项 iPad 界面测试通过。包括文件导出、无 iCloud 权限时的明确提示、轮次横杠点击/拖动以及系统滚动条拖动。1.7.0（14）已安装并启动于 iPhone 15 Pro。

轮次短横线位于阅读区左侧，保留圆角、点击/拖动跳转和触感反馈；右侧使用 UIKit 自带滚动条。已删除窗口级自定义拖动手势和反复闪现滚动条的逻辑，长按放大及拖动由系统处理。自动化验证原生滚动条与轮次标记分别位于两侧；瞬时放大手势受测试工具等待滚动结束的限制，未完成真机手势验证。

顶部标签和底部输入框改为独立覆盖层，仅移动和淡出，正文滚动区及边距保持稳定。阅读位置采用原生滚动坐标恢复；分页使用本地状态与模型选择同步，修复标签切换后正文偶尔仍停留在前一个模型的问题。新一轮消息仍定位到发送消息的开头。

### 1.9.0：抽屉交互与透明玻璃

主页面向右移动并露出下方的会话抽屉，左侧上下角随展开形成圆弧；手指从屏幕左边缘向右拖动可展开抽屉，其他位置左右滑动仍切换模型。拖动与松手动画使用同一个进度，避免松手时回跳。展开期间右侧消息逐渐淡化；进入设置后保留抽屉。

抽屉顶部只显示 Loom 名称，右上角提供搜索按钮，点击展开搜索框并弹出键盘；底部提供紧凑的“聊天”和设置按钮。搜索框及正文均支持向下拖动收起键盘；正文向上滚动保持键盘。顶部模型标签和底部输入框始终显示。底部输入框使用可交互的 regular Liquid Glass，周围保持全透明；顶部状态栏与模型标签共享一整块玻璃，底部边界直接分隔正文。

轮次短横线移入更易点击的位置，扩大点击范围并覆盖在正文之上；背景采用向四周淡出的浅透明材质。切换历史会话增加触觉反馈；离开没有消息、草稿或引用的空白新会话时将其移除，有输入草稿则保留。默认单击高亮，保留用户显式选择的双击设置。App 增加简体中文本地化，系统长按编辑菜单显示中文。

阅读性能调整包括 Markdown 渲染与文本尺寸缓存、滚动状态隔离，以及当前会话提前布局，避免进入轮次边界时才创建长回复。提前布局会增加长会话的初始布局及内存开销；轮次边界卡顿是否完全消失仍需真实设备验证。


验证：33 项单元测试通过；iPhone 的侧栏搜索下滑收键盘、新建/搜索/切换会话、输入框展开、固定上下栏及滚动位移检查通过。真机签名构建通过，1.9.0（16）已安装到 iPhone 15 Pro。触觉反馈与长会话滚动流畅度仍需真机体验。

#### 输入框、顶部玻璃与搜索键盘布局

输入框外部不增加半透明背景，输入框本身使用 regular Liquid Glass，降低透视强度以保证输入文字清楚。顶部使用从屏幕顶端延伸至标签下沿的单一玻璃面板，底边就是标签与正文的边界，移除独立分隔线及渐隐叠层。面板增加透视、裁掉边界外的阴影；标签上下留白压缩，标签上移并减少顶部占用高度。高亮引用标签的黄色背景使用 90% 不透明度（约 10% 透明度）。顶部标签上下采用对称留白，整个标签区向上微调。

抽屉右上角只显示搜索按钮，点击后展开输入框并获得焦点；下滑收起键盘时同步收起搜索框并清空筛选。抽屉展开时，在页面横向向左拖动即可关闭抽屉；垂直滚动和模型选择不受影响。历史删除改由长按会话菜单进入，并保留确认框。搜索时整个工作区忽略键盘底部避让，让“聊天”、设置及右侧页面底部控件保持原位，由键盘遮挡；正文输入时仍正常避让键盘。模拟器的屏幕键盘呈现受运行环境限制，按钮避让仍需真机复核。

本次界面检查通过，包含搜索按钮展开输入框、下滑同步收起输入框与键盘、左滑关闭抽屉且不切换模型、设置返回后保留抽屉，以及长按删除的取消和确认；已核对搜索收起后的截图。


#### 系统蓝与跟手收起

控件、选中模型、轮次标记及用户消息底色统一使用系统蓝。引用标签采用浅荧光黄，保持约 10% 透明，并提供深色模式颜色。顶部模型标签位置保持不变，仅将整块玻璃底边下延 4 点。

抽屉关闭改为整个工作区的连续拖动：手指移动直接更新同一展开进度，松手依据位置及速度完成关闭或回弹；垂直滚动和搜索键盘下滑不触发水平收起。


### 1.10.0：模型启用与直连

设置中的每个已添加模型都有启用开关。关闭后不参与新消息发送、不会创建新的用户消息，并隐藏模型标签及对应阅读页面；重新开启会恢复历史页面，不删除消息、配置或密钥。关闭当前选中模型会切换到另一个已启用模型。全部关闭时保留草稿，并提供“启用模型”的入口；生成中暂不能改变启用状态。开关写入本地文件及备份，旧数据缺少该字段时默认启用。

移除“使用转发服务”及服务地址配置，发送消息和获取在线型号均直接请求模型接口。旧文件和备份中的转发字段仍可读取，但不会恢复转发行为；新保存的数据标记为直连。直连访问能否成功仍取决于配置的服务商接口和设备网络。

修复抽屉松手时闪消：关闭时保留抽屉视图直到正文页面的覆盖动画结束，再卸载；连续打断动画时仅由最新动画执行清理，避免旧动画提前移除抽屉。搜索键盘的底部布局在关闭动画期间继续保持固定。


验证：36 项单元测试通过，包含关闭模型不发送、开关持久化与备份恢复、旧字段默认值及旧转发设置迁移。模型页面隐藏/恢复、全部关闭的入口、抽屉开关及搜索收起的针对性界面测试通过。1.10.0（17）真机签名构建通过并安装到 iPhone 15 Pro。

### iPhone Duo 自适应布局

iPhone 支持竖屏及左右横屏。阅读布局按实时窗口宽度决定：小于 700 pt 使用单列模型分页，达到 700 pt 使用并排阅读，适用于 Duo 内外屏及旋转后的窗口。切换布局时同步当前模型，并将宽屏阅读区定位到已选择的模型；草稿、引用和会话继续保存在同一工作区状态中。

验证：iPhone 18 Pro 模拟器的 36 项单元测试及旋转界面测试通过，覆盖模型选择和草稿保留、横屏并排布局、返回竖屏后的当前回答。iPad mini 的旋转状态保留及并排阅读两项界面测试也通过。当前 Xcode 未提供 Duo 模拟器，内外屏折叠切换仍需 Duo 设备或对应模拟器验证。
