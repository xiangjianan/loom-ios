# Loom 隐私政策

更新日期：2026 年 10 月 18 日。适用于 Loom iPhone 与 iPad 应用。

## 本机数据

Loom 无需注册账户。对话、草稿、高亮、模型配置和偏好保存在设备的应用目录中；API Key 单独保存在系统钥匙串中。本版本不包含广告、行为分析或第三方统计 SDK，也不会把对话上传到开发者运营的服务器。

## 模型服务商

当你填写有效的模型接入配置和 API Key 后，应用会自动尝试获取模型列表；你也可以手动刷新。当你获取模型列表或发送问题时，Loom 会通过 HTTPS 直接请求你配置的服务商地址。服务商会收到认证所需的 API Key；对话请求还包含所选模型、问题、该模型的对话上下文和引用内容。启用多个模型时，请求会分别发送到各模型配置的服务商。服务商也可能获得 IP 地址等网络信息。

这些服务商依照各自的隐私政策处理、保留数据，并可能在其他国家或地区处理请求。请在使用前查看所选服务商的政策，确认接入地址可信，不要发送你无权分享的信息。Loom 的开发者无法替你删除服务商已收到的数据。

## 备份与分享

导出备份、复制和分享均由你主动触发。备份默认不包含 API Key；只有开启“同时备份 API Key”时才会包含密钥。备份文件未额外加密，请妥善保存，避免分享包含密钥的文件。

你可以通过系统“文件”将备份保存到 iCloud Drive 或其他位置，其存储由对应服务提供方管理。本版本未启用直接 CloudKit 云备份，也没有自动跨设备同步。

## 删除与管理

你可以在应用中删除对话，或在模型设置中移除模型。移除模型会保留已有的非空对话记录；只要历史对话仍引用该模型，对应 API Key 也会保留在钥匙串中。卸载应用会移除应用目录内的数据，但钥匙串中的密钥可能保留。如需使旧密钥彻底失效，请前往对应服务商的控制台撤销密钥。此前导出的备份、导入前保留的本机副本，以及已发送给服务商的内容，不会随单条对话删除而自动清除。导出的备份需在保存位置另行删除。

点击应用内外部链接时，浏览器会访问相应网站，该网站按其自身政策处理网络请求。

## 联系与更新

隐私相关问题可通过 [Loom 支持页面](https://github.com/xiangjianan/loom-ios/issues) 联系开发者。公开提问时请勿附上 API Key、私人对话或其他敏感信息。数据处理方式发生变化时，本页面会更新日期与说明。
